移动软件开发 | 实验/项目 README

📌 项目简介
本仓库为中国海洋大学2026夏季学期《移动软件开发》课程配套学习仓库，用于存放课程所有上机实验代码、个人项目源码、实验报告及相关学习资料。本课程以移动端应用开发能力培养为核心，重点讲授微信小程序开发基础，本年度新增鸿蒙开发实验内容，通过实验实操与个人项目实战，循序渐进掌握移动端开发核心技能，夯实移动开发工程基础。
仓库包含课程全部实验作业、阶段性项目成果、学习总结文档，严格遵循课程提交规范与代码开源要求，满足课程考核、加分项归档需求。

📊 课程成绩构成
课程总成绩由实验成绩、项目成绩、奖惩分及考勤构成，评分公开透明，各项成绩统一公示：
- 个人实验成绩：60%（共3周实验，单次实验满分10分）
- 个人项目成绩：40%（4周项目迭代，期末公开互评打分）

💻 开发环境与技术栈
- 核心工具：微信开发者工具（稳定版）

- 核心技术：微信小程序原生开发（WXML、WXSS、JS、JSON）

🚀 运行说明
1. 安装最新版微信开发者工具，完成账号授权登录；
2. 克隆/下载对应实验/项目源码至本地；
3. 打开开发者工具，选择「小程序」项目类型，导入本地项目文件夹；
4. 使用测试号AppID，关闭云服务，编译运行项目；
5. 模拟器查看运行效果，核对功能完整性，完成调试。

📚 学习说明与总结
本课程从零基础入门移动端开发，以微信小程序为核心教学载体，搭配鸿蒙拓展实验，通过「课堂理论+上机实操+个人项目」的模式，系统培养移动端应用开发能力、代码调试能力与工程文档撰写能力。
所有实验与项目严格遵循课程规范开发，代码结构整洁、注释完整，实验报告排版规范，同时主动完成代码开源、博客复盘等加分项任务。通过阶段性实操与项目迭代，熟练掌握小程序开发全流程，理解移动端开发的核心逻辑与工程规范，为后续移动端进阶开发、项目实战积累扎实的技术基础。
